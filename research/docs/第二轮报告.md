# 第二轮研究报告：中美制度差异与全球传导

> 全球股市研究团队 · 2026年10月17日（台北时间）· 第二轮 · 已采纳风险审查员的全部修订 · 不构成投资建议

## 一句话结论

第二轮一共正式检验了 9 个说法，**没有一个过及格线**。总主线“制度决定冲击走哪条管道”的判定是**〔待验证〕（未判定）**：这一轮的数据既没有支持它，也没有推翻它。最大的问题是检验力太低，样本太少，很多检验就算关系真的存在也很难查出来。

## 先看懂几个词

| 词 | 大白话 |
|---|---|
| 预注册 | 先把规则写死，再去看数据，避免“看了结果再改规则” |
| 验证性 / 探索性 | 验证性：完全按锁定的规则做，结果算数。探索性：执行时和规则有出入，结果只能参考，不升级为结论 |
| 本轮尚未检出 | 没过及格线。不等于证明不存在，只是这次没查出来 |
| 及格线（门槛） | C 家族最严 0.01，L 家族 0.0125。p 值要低于它才算“查出来了” |
| 95% 区间 | 效应大小的合理范围。区间里的任何大小都和数据相容 |
| 检验力 / MDE | 关系真存在时能查出来的把握。MDE 是“有 80% 把握查出来所需的最小效应”。检验力低时，没查出来说明不了什么 |

## 一、这一轮检验了什么

本轮的总主线是：**制度决定冲击走哪条管道**。开放市场（港股、中概股、日元套利盘）用价格吸收冲击，封闭市场（A股）用政策吸收，代价转到 AH 溢价和降准降息上。

围绕主线，本轮登记了两组检验：

- **C 家族，中美市场机制**（正式 5 项）：
  - C4：芯片管制后中概股有没有异常下跌
  - C5：A股是不是信贷政策市
  - C6：降准降息后有没有反弹
  - C9：美国紧缩周 AH 溢价是否扩大
  - C10：芯片管制是否利好 A股半导体
- **L 家族，杠杆、黄金、油价、台韩**（4 项）：
  - L1：日元套利是不是“杠杆开关”
  - L2：黄金是否变成去美元化资产
  - L3：油价冲击是否伤欧股多于美股
  - L4：台韩是不是中美博弈的夹心层

主线不单独算 p 值，由 C9、C6、L1 三项按判定表来判。

## 三、主线判定：未判定

| 检验 | 结果 | 归类 |
|---|---|---|
| C9 | 方向是“溢价扩大”，但没过及格线 | 本轮尚未检出 |
| C6 | 方向是“反弹”，但没过及格线 | 本轮尚未检出 |
| L1 | 秩相关不显著；“日经多跌”这部分不能用 | 未判定 |

**没有推翻，也没有支持 → 主线〔待验证〕（未判定）。** “未判定”不是替主线解围，它的意思是这一轮什么都没证明，不能写成“部分支持”。

初版结果曾写“L1 推翻主线”，审查后撤回：
- 那一版是用美元计价的篮子，去减日元计价的日经。
- 这些事件本来就是“日元急升”的日子，日元平均升值 2.4%。所以算出来的“日经多跌”，几乎全是汇率换算造成的。
- 换成同样用美元计价以后，两边跌幅看不出差别。

## 四、审查员指出的问题与修正

风险与方法论审查员逐项核对了时间戳、指纹和数值，总架构师采纳了全部 10 条修订：

1. **撤回“L1 推翻主线”和“被否”的说法**，改为“本轮未获支持，尚未检出”，主线判为“未判定”。
2. **HSAHP 改判为通过**。原版用了临时加严的标准判“不通过”，属于偏离。C9 改回 HSAHP 主口径，自建名单降为稳健性检查。两版结论一样，没有挑结果的空间。
3. **6 项降为探索性**（C4、C5、C6、C10、L2、L4）：
   - 共享事件清单和群里锁定的规则有四处不符：日期、合并、排除词、新增的筛选。
   - C4 的基准和窗口改了。
   - C5 的社融口径不对，检验力也没有事先公布。
   - C6 多加了一个控制变量。
4. **C 家族 N 保持 5**。降级不缩小 N，否则就是按结果调门槛。
5. **补齐 C5 修 bug 前的数值**：前两次能算出数值的运行，p 是 0.940 和 0.930；最终 p 是 0.333。三次都远未过线，结论不变。
6. **删掉一句错话**：“没查出来，说明效应比 MDE 小”。这句不成立。能说的只有：95% 区间里的效应大小，都和数据相容。
7. **补写局限**：
   - C10 里有一个异常值，2024-10-08 那天 +9.6pp，正赶上国内刺激政策行情。
   - L4 的两边时差一天，币种也不同。
   - L3 的周界线错开一个交易日。
8. **数据时点声明**：指数点位和 CFTC 数据在细则写定之前就已经在盒子上了。执行者声明当时没有计算任何事件收益，这一点无法独立核实。

## 五、这一轮的教训

- **检验力太低，是最大的问题。** 多数检验的 MDE 都比现实中可能的效应大。比如 C6 要反弹超过 2.2 个百分点才查得出来，L1 的相关系数要达到 0.5 才查得出来。这样的设计，“没查出来”几乎是注定的。下一轮开跑前，要先算好并公布 MDE；检验力不到 50% 的项目，不进验证性家族。
- **执行偏离比数据本身更伤人。** 6 项降级，原因都是执行时改了规则：临时补细节、换基准、换窗口、新加筛选。下一轮的规则要一次写全，事件清单单独锁定、单独审查。
- **币种要先统一。** L1 的教训：用两种货币相减，会把汇率变动错当成结论。
- **修订另存新文件。** 不要在锁定文件末尾追加内容，免得指纹对不上。
- **原始资料要落盘。** HSAHP 的一个“官方数”只来自网页摘录，原文件没有下载到，事后就无法核实。
