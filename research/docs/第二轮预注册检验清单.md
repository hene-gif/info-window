# 第二轮预注册检验清单

> 全球股市研究团队 · 2026年10月16日（台北时间）· 第二轮 · 开跑前登记，还没看任何收益数据 · 不构成投资建议

## 一句话说明

这份清单是在**看收益数据之前**写好的规则：查什么、用什么数据、怎样算“支持”、怎样算“推翻”。所有项目都还没跑，一律标〔待验证〕。结果出来后，结论最高只到〔相关〕；没过门槛的写“**本轮尚未检出**”，不算推翻。

## 先看懂几个词

| 词 | 大白话 |
|---|---|
| 预注册 | 先把规则写死、交给你确认，再去看数据，避免“看了结果再改规则” |
| 〔待验证〕 | 已经登记、还没跑出结果 |
| 〔相关〕 | 经常一起动，但还不能说谁推动谁。本轮结论最高只到这一级 |
| N 与门槛 | N 是一个家族里正式检验的项数。项数越多，及格线越严：C 家族 0.05/7≈0.0071，L 家族 0.05/4=0.0125 |
| 95% 区间 | 效应大小的合理范围。区间“不含 0”，说明方向比较确定 |
| 检验力 | 如果关系真的存在，这个检验能把它查出来的把握有多大。检验力低时，“没查出”说明不了什么 |
| 样本外 | 先用前一段数据把模型定死，再拿从没用过的后一段数据去检验 |
| 探索项 | 只看看、只描述，不占 N，结果再好本轮也不升级为结论 |

## 一、总主线（理论层）〔待验证〕

**核心说法：制度决定冲击走哪条管道。**

| 市场 | 怎样吸收冲击 | 代价出现在哪里 |
|---|---|---|
| 开放市场：港股、中概股、日元套利盘 | 用**价格**吸收 | 价格直接下跌 |
| 封闭市场：A股 | 用**政策**吸收，价格被托住 | 转到 AH 溢价扩大，以及随后的降准降息 |

| 台韩芯片链 | 可能两边获利的中间地带 | — |

主线**不新算 p 值，不占 N**，只根据下面三项的结果来判定。

| 检验 | 支持 | 推翻 | 其余 |
|---|---|---|---|
| C9 | 美国紧缩周 AH 溢价扩大，并过门槛 | 收窄，且 95% 区间不含 0 | 本轮尚未检出 |

| 三项合起来 | 主线判定 |
|---|---|

| 编号 | 检验的问题 | 状态 |
|---|---|---|

| C4 | 中美摩擦事件后，中概股（KWEB）有没有异常收益 | 〔待验证〕 |
| C5 | A股是不是“信贷政策市” | 〔待验证〕 |

**C1 紧缩周成长股对价值股**〔待验证〕

- 美国紧缩周里，比较成长股和价值股的表现。

**C2 美股盈利的预判力**〔待验证〕

- **方法**：两种比较预测好坏的标准检验。模型一个包含另一个时用 Clark-West，不包含时用 Diebold-Mariano；都控制 CAPE（周期调整市盈率）。
- **数据**：Shiller 数据，来自 shillerdata.com（价格到 2026-10，盈利到 2026-06）。每个月只用“当月已经能看到的最新一期”盈利，不偷看未来。
- **样本外**：2010–2017 定模型，2018 年起样本外检验。

**C4 中美摩擦事件：KWEB 异常收益**〔待验证〕

- KWEB 从 2013-07 起有数据。
- 对齐到公告后第一个交易时段。
- 全球基准和行业基准两种算法都报告。

**C5 A股是信贷政策市**〔待验证〕

- **数据**：沪深 300 指数 000300（东方财富接口，2005-01-04 起），用 510300.SS 交叉核对。指数不含分红，写进局限。
- **社融**：从 2016-01 开始（月度存量从这时起连续），用最新修订口径。
- **样本外**：2016–2020 定模型，2021 年起样本外。独立区间约 11 个，**检验能力低**，开跑前要写明。
- **判定**：社融的预测增益显著 = 支持。
- **“美国实际利率无效”改成可判定的说法**：它的预测增益 95% 区间上限低于社融的增益，才算成立；否则写“无法判定”。

**C6 临时降准降息**〔待验证〕

- **主检验**：降准降息后 5 天的反弹，是否高于跌幅相近的对照组。
- **“只管一阵”改成可判定的说法**：第 6–20 天超额收益显著为负，才算成立；否则写“持久性未判定”。
- **对照**：只控制美国实际利率和 MSCI World（URTH）。
- 事件少于 15 个，降为探索项。

**C9 A+H 同一公司（AH 溢价）**〔待验证〕

- **主口径**：恒生 AH 溢价指数 HSAHP（东方财富，2006-01-03 起）。前提是先用官方公开收盘值核对通过，并查清它怎样处理汇率。
- **核对不通过 → 自动改用自建名单**：
  - 2010-01-01 之前已在 A、H 两地上市、至今仍在交易的全部公司，等权；
  - 名单先冻结、注明日期，再下载价格；
  - 流动性门槛：2010–2012 年两边都有成交的周数 ≥ 90%；停牌按缺失处理；
  - 另报剔除金融股的版本（探索），并报行业权重。
- **汇率**：用 DEXCHUS 和 DEXHKUS 算出人民币兑港元，把 H 股换成人民币后再和 A 股比（主口径）；两边各用本币、直接相减，只作对照。
- **对齐**：每周取最后一个三边都有数据的交易日。
- **局限**：HSAHP 按市值加权，金融股占比高。

**C10（新增）美国芯片管制利好 A股半导体**〔待验证〕

- **指数**：中证全指半导体 H30184（2013-07-15 起）；核对不通过就改用国证芯片 980017。基准为沪深 300。
- **对齐**：公告后第一个 A股交易日。
- **事件**：只收 BIS 出口管制和实体清单中涉及半导体的条目，用《联邦公报》原文，按事先定好的关键词机械筛选。关键词清单开跑前贴出。
- 这是对已知现象的正式检验，**通过也不加分**。

**L2 黄金：从利率资产到去美元化资产**〔待验证〕

- 央行购金只有季度数据，从主检验中拿掉。

**L3 油价冲击伤欧股多于美股**〔待验证〕
