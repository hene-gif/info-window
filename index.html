单独开一扇窗口

还是这个讯息窗。用 Chrome 或 Edge 装上之后，它会在自己的窗口里打开，拖边缘就能改大小。浏览器会先问你。不会开机自己启动，不会一直浮在别的窗口上面，也不会要通知权限。

  1. 用 Chrome 或 Edge 打开现在这个页面。
  2. Chrome 优先点地址栏右端的「安装应用」。英文界面写的是 Install。
  3. 没有图标时，Chrome 点右上角「更多」→「投放、保存和分享」→「安装“讯息窗”」。若写成「将网页作为应用安装」，也是这一项。英文是 More → Cast, save, and share → Install page as app。
  4. Edge 点右上角「…」→「更多工具」→「应用」→「将此站点安装为应用」。英文是 Settings and more → More tools → Apps → Install this site as an app。
  5. 确认之后，开始菜单里搜「讯息窗」就能打开。想钉在任务栏，用装好时的询问，或以后到 chrome://apps、edge://apps 里固定。

窗口关着，或者电脑睡着，就不会核对。醒来后只要这扇窗口还开着，会接着看有没有新发布的一期。一天大约三期，不是一直在抓新闻。若看到「登录时启动」，那是浏览器自己的开关，不勾即可。
